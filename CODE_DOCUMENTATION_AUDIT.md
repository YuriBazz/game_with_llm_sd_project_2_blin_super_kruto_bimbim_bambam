### 2. Player бонусы (Player.hpp)
**Документация:** 
- Max урона: +4 (85% от базовых 5)
- Max сопротивления: 66%

**Код:**
```cpp
void recalculate_passives() {
    current_damage_bonus = std::min(current_damage_bonus, 4);    // ✅ +4
    current_resistance = std::min(current_resistance, 66);       // ✅ +66%
}

int apply_resistance(int incoming_damage) const {
    int reduced = incoming_damage * (100 - current_resistance) / 100;
    return std::max(1, reduced);  // ✅ Минимум 1 урон
}
```
✅ **СООТВЕТСТВУЕТ**
