# Item System: Passive & Active Effects

## Обзор

Система предметов разделена на **пассивные** и **активные** эффекты:

| Тип | Применение | Примеры |
|-----|-----------|---------|
| **Пассивные** | Автоматически (пока предмет в инвентаре) | Меч (+урон), Броня (+сопротивление) |
| **Активные** | Вручную через `/api/use_item` | Зелья восстановления (+HP) |

## Лут система

### Дроп вероятности (при убийстве врага)

- **40%** → Зелье восстановления (Potion) — **активный** эффект
- **15%** (от оставшихся 60%, т.е. > 85) → Меч (Sword) — **пассивный** эффект
- **35%** (от оставшихся 45%, т.е. 50-85) → Броня (Armor) — **пассивный** эффект
- **10%** → Ничего

### Лут доступен ТОЛЬКО герою
- Враги **не могут** подбирать лут
- Герой подбирает лут автоматически командой `/api/pickup_item`

## Пассивные эффекты

### Структура предмета (пассивный)

```cpp
struct Item {
    std::string id;                    // "sword", "armor"
    std::string name;                  // "Iron Sword", "Steel Armor"
    std::string type;                  // "weapon", "armor"
    int count = 1;                     // Количество (для потребляемых)
    
    // Пассивные бонусы
    int passive_damage_bonus;          // Увеличивает урон
    int passive_resistance_bonus;      // Процент сопротивления урону
    
    // Активные эффекты
    std::string active_effect;         // "heal", "" - нет
    int active_value;                  // Значение эффекта
};
```

### Механика

1. **Автоматический расчёт** при подборе предмета:
   ```cpp
   player.pickup() → player.recalculate_passives()
   ```

2. **Пересчёт пассивов**:
   ```cpp
   void recalculate_passives() {
       current_damage_bonus = 0;
       current_resistance = 0;
       
       for (auto item : inventory) {
           current_damage_bonus += item.passive_damage_bonus;
           current_resistance += item.passive_resistance_bonus;
       }
       
       // Ограничения
       current_damage_bonus = min(current_damage_bonus, 4);  // макс +85% = 4
       current_resistance = min(current_resistance, 66);     // макс +66%
   }
   ```

3. **Применение при атаке**:
   ```cpp
   attack_damage = get_total_damage(kPlayerDamage)
                 = kPlayerDamage + current_damage_bonus
                 = 5 + current_damage_bonus
   ```

## Активные эффекты

### Структура

Только для потребляемых предметов (`type = "consumable"`):

```cpp
active_effect = "heal";   // Тип эффекта
active_value = 20;        // Значение (+20 HP)
```

### Механика

1. **Использование** через API:
   ```
   POST /api/use_item
   {"item_id": "potion"}
   ```

2. **Выполнение**:
   ```cpp
   if (item.active_effect == "heal") {
       player.hp += item.active_value;
       item.count--;
   }
   ```

3. **Ответ**:
   ```json
   {
     "success": true,
     "effect": "heal",
     "value": 20
   }
   ```

## Сопротивление урону

### Применение при получении урона от врага

```cpp
incoming_damage = 2;  // базовый урон врага
final_damage = player.apply_resistance(incoming_damage)
             = incoming_damage * (100 - player.current_resistance) / 100
             = 2 * (100 - 20) / 100
             = 1 (с броней +20%)
```

### Минимум урона

**Гарантированный минимум 1 урон** даже при 66% сопротивлении:
```cpp
return std::max(1, reduced);
```

## Примеры сценариев

### Сценарий 1: Герой с мечом и броней

```
Инвентарь:
  - Меч (+2 урона)
  - Броня (+20% сопротивления)

Атака врага:
  - Базовый урон = 5
  - С мечом = 5 + 2 = 7 урона враг получит
  
Получение урона:
  - Враг бьёт (базовый 2 урона)
  - С броней = 2 * (100 - 20) / 100 = 1 урон герой получит
```

### Сценарий 2: Максимальные бонусы

```
Инвентарь:
  - Меч +2 урона
  - Меч +2 урона
  - Броня +20% сопротивления
  - Броня +20% сопротивления
  - Броня +20% сопротивления
  - Броня +6% сопротивления (+20 дальше отсечется)

Расчёт:
  - Урон: 2 + 2 = 4 (макс 4, ограничено)
  - Сопротивление: 20 + 20 + 20 + 6 = 66 (макс 66, ограничено)
  
Результат:
  - Атака: 5 + 4 = 9 урона
  - Защита: враг 2 урона → герой получит max(1, 2 * 34 / 100) = 1 урон
```

## Расширение системы

### Добавить новый пассивный предмет

1. Обновить `drop_loot()` в State.cpp:
```cpp
else if (chance > 70) {
    Item ring {
        "ring_of_power", "Ring of Power", "ring", 1,
        3, 0,  // +3 урона, без сопротивления
        "", 0
    };
    drop_loot(target->x, target->y, ring);
}
```

2. Пересчёт автоматический через `recalculate_passives()`

### Добавить новый активный эффект

1. Обновить Item структуру (если нужны новые параметры)
2. Обновить `use_item()` в State.cpp:
```cpp
if (it->active_effect == "poison_cure") {
    // remove poison debuff
    result.success = true;
}
```

## Баланс ограничений

| Параметр | Значение | Причина |
|----------|----------|---------|
| **Макс урона** | +4 (+85% от 5) | Враги тугие на урон (10 HP) |
| **Макс сопротивления** | 66% | Враги всё равно опасны (минимум 1 урон) |
| **Базовый урон врага** | 2 | Контролируемо с броней |
| **Зелье восстановления** | +20 HP | Max HP = 30, чуть чинит |
